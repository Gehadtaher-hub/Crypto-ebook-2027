Fundamentals of Cryptography

1. Essential terminology

Plaintext

Original readable information.

Ciphertext

Transformed unreadable output.

Encryption

Converts plaintext to ciphertext using an algorithm and key.

Decryption

Recovers plaintext using the corresponding key.

C = E(K, P)   and   P = D(K, C)

2. Basic cryptographic process

Sender plaintext → encryption algorithm + key → ciphertext → communication channel → decryption + key → receiver plaintext.

Kerckhoffs’s principle: A system should remain secure even when everything except the key is public.
Predict: If an attacker knows the algorithm but not a strong secret key, should the system automatically fail?
No. Modern cryptography assumes algorithms are known; security depends primarily on protected keys and sound design.

3. Security goals

Confidentiality

Prevents unauthorized disclosure.

Integrity

Detects unauthorized modification.

Authentication

Verifies identity or message origin.

Non-repudiation

Provides evidence so an action cannot easily be denied.

4. Cryptosystem types

Symmetric

The same shared secret key encrypts and decrypts. Fast, but key sharing is challenging.

Asymmetric

A public/private key pair supports encryption, signatures, and key exchange.

Hash function

Produces a fixed-size digest and is not designed for decryption.

Hybrid system

Combines public-key setup with efficient symmetric data encryption.

5. Attack models

Ciphertext-only

Attacker has ciphertext samples.

Known-plaintext

Some plaintext/ciphertext pairs are known.

Chosen-plaintext

Attacker can obtain encryption of selected messages.

Chosen-ciphertext

Attacker can obtain decryption of selected ciphertexts under restrictions.

Brute force: tests possible keys. A sufficiently large keyspace makes exhaustive search impractical, but implementation weaknesses may still bypass it.

6. Keys and key management

Security depends on secure key generation, distribution, storage, rotation, revocation, backup, and destruction.

Possible keys: 2^8 = 256

7. Applications, limitations, and mistakes

Applications

Secure web traffic, messaging, storage, digital signatures, payments, and software updates.

Limitations

Cryptography does not fix weak passwords, compromised endpoints, social engineering, or incorrect access control.

Common mistakes

Hard-coded keys, key reuse, obsolete algorithms, insecure random numbers, and custom unreviewed designs.
