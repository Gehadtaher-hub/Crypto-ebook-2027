3. Playfair and Hill ciphers

Playfair

Encrypts letter pairs using a 5×5 keyword matrix, concealing simple single-letter frequencies.

Hill

Uses invertible matrices and modular arithmetic to transform blocks of letters.

Hill’s key matrix must have an inverse modulo 26, otherwise ciphertext cannot be uniquely decrypted.

4. Vigenère, Vernam, and one-time pad

Vigenère cycles through shifts selected by a repeating keyword. A true one-time pad requires a random, secret, message-length key that is never reused.

Classic result: LXFOPVEFRNHR
Warning: Reusing a one-time-pad key destroys its security.

5. Rail Fence and columnar transposition

Rail Fence writes text in a zigzag and reads across rows. Columnar transposition writes beneath a keyword and reads columns in key order.

6. Frequency analysis and cryptanalysis

Brute force

Tests possible keys.

Frequency analysis

Compares symbol counts with language patterns.

Pattern analysis

Uses repeated letters, digraphs, and word shapes.

Known plaintext

Uses known message fragments to infer transformations.

7. Steganography and information hiding

Cryptography hides meaning, while steganography hides the existence of a message within a cover such as an image, audio file, or text.

Cryptography

Produces protected data that may look suspicious.

Steganography

Attempts to make communication unobtrusive.

Combined approach

Encrypt the message first, then hide the ciphertext.
