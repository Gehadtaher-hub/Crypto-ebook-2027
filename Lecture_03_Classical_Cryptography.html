1. The classical cipher model

A plaintext message P is transformed by an encryption algorithm using a key K to produce ciphertext C. Decryption applies the inverse transformation.

C = EK(P)    and    P = DK(C)
Substitution

Symbols are replaced, but their positions are mostly preserved.

Transposition

Symbols remain unchanged, but their positions are rearranged.

Product approach

Multiple substitution and transposition stages can be combined to increase complexity.

Key idea: Keeping an algorithm secret is not a reliable security strategy. The key should be secret, while the algorithm may be public.

2. Substitution ciphers

Caesar shift cipher

Each letter is shifted by a fixed key within the 26-letter alphabet. Using A=0 through Z=25:

Encryption: C = (P + K) mod 26   |   Decryption: P = (C − K) mod 26

Monoalphabetic substitution

A complete scrambled alphabet forms the key. Its large keyspace defeats simple brute force, but natural-language letter patterns remain visible.

Weakness: The same plaintext letter always maps to the same ciphertext letter, so frequency and pattern analysis can reveal the mapping.

Playfair and Hill ciphers

Playfair

Encrypts letter pairs using a 5×5 keyword matrix. Digraphs hide single-letter frequency better than monoalphabetic substitution.

Hill

Encrypts blocks as vectors using matrix multiplication modulo 26. The key matrix must be invertible modulo 26.

3. Polyalphabetic and stream-style classical ciphers

Vigenère cipher

A repeating keyword selects a different Caesar shift for each character, reducing the visibility of single-letter frequencies.

Classic example result: LXFOPVEFRNHR

Vernam cipher and one-time pad

The Vernam principle combines message symbols with key symbols. A true one-time pad provides perfect secrecy only when the key is genuinely random, as long as the message, kept secret, and never reused.

Critical warning: Reusing a one-time-pad key destroys its security because relationships between plaintexts can be exposed.

4. Transposition ciphers

Rail Fence cipher

The message is written diagonally across rails, then read row by row. The letters are unchanged, only their order moves.

Result appears here.

Columnar transposition

Plaintext is written in rows beneath a keyword, then columns are read according to the alphabetical order of key letters. Repeated transposition produces more complex permutations but preserves plaintext letter frequencies.

5. Cryptanalysis of classical ciphers

Brute force

Try every possible key. This is especially effective against Caesar’s 26 possible shifts.

Frequency analysis

Compare ciphertext symbol frequencies with expected language frequencies such as E, T, A, and common pairs.

Pattern analysis

Repeated letters, digraphs, word shapes, and repeated sequences provide structural clues.

Known plaintext

Matching a known message fragment with ciphertext may expose the key or transformation.

Think: Which cipher type preserves exact single-letter frequencies: substitution or transposition?
Transposition. It rearranges the original letters without replacing them.

6. Information hiding and steganography

Cryptography conceals a message’s meaning. Steganography conceals the message’s existence inside a cover medium such as an image, audio file, video, or formatted text.

AspectCryptographySteganography
Main goalHide meaningHide existence
Visible outputUsually obvious ciphertextApparently ordinary cover object
Failure consequenceAttacker still needs to break encryptionDiscovery may expose the hidden communication
Best practiceUse both when appropriate: encrypt first, then hide the ciphertext.
Least significant bit concept: Image data can carry hidden bits through very small changes to low-impact color bits. Capacity, detectability, and image format affect reliability.

7. Summary map

Caesar

One fixed shift; tiny keyspace.

Monoalphabetic

One fixed scrambled alphabet; vulnerable to frequency analysis.

Playfair

Digraph substitution using a 5×5 matrix.

Hill

Block substitution using matrices modulo 26.

Vigenère

Repeating-key polyalphabetic substitution.

One-time pad

Perfect secrecy under strict key conditions.

Rail Fence

Zigzag transposition.

Steganography

Hides the existence of information.
